# Мок-сервер 동네 SOS

Заглушка backend API на 9 endpoint'ов из §11 архитектуры. Пока настоящий
Node+Express сервер не готов, фронтенд (мобильное приложение + админка)
работает против этого мока и не ждёт бэкенд-разработчика.

## Запуск

```bash
npm install
npm start
```

Сервер поднимется на `http://localhost:3000`. Проверить, что жив:

```bash
curl http://localhost:3000/health
```

Для автоперезапуска при правке кода:

```bash
npm run dev
```

## Структура

- `server.js` — сам сервер и все 9 маршрутов
- `fixtures.json` — стартовые данные (2 заявки, фото, история статусов).
  При перезапуске сервера данные сбрасываются к этому файлу — это нормально,
  так и задуман мок.

## Данные для теста

Готовая заявка с историей и фото:
`r0000000-0000-0000-0000-000000000001`

## Подключение с телефона/эмулятора

`localhost` с реального телефона или Android-эмулятора не работает —
там это будет обращение к самому телефону, а не к твоему компьютеру.

- **Android-эмулятор:** используй `http://10.0.2.2:3000`
- **Реальный телефон (тот же Wi-Fi):** узнай IP компьютера (`ipconfig` /
  `ifconfig`) и используй `http://192.168.х.х:3000`
- **Expo Go:** удобнее всего вынести адрес в `.env` фронтенда
  (`API_URL=http://192.168.х.х:3000/api`), чтобы не хардкодить

## Дальше

Когда настоящий backend будет готов на том же контракте
(`contract/types.ts` + `fixtures.json`), фронтенду достаточно поменять
`API_URL` — код экранов трогать не придётся.
